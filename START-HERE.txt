万能转码 AnyConvert 1.5.0 · Windows / Linux / macOS 免安装包
==============================================================

1) 安装 Python 3.10 或更新版本（安装时勾选 Add Python to PATH）。

2) 安装依赖（在解压目录执行）：
   python -m pip install -r crossplatform/requirements.txt

3) 准备引擎（任选其一）：
   A. 自动下载（推荐，需联网一次）：
      python scripts/fetch_engines.py --all
   B. 使用系统已安装的 FFmpeg / LibreOffice，跳过本步骤。

4) 启动：
   Windows：双击  启动-Windows.bat
   Linux：  bash 启动-Linux.sh
   macOS：  双击  启动-macOS.command

浏览器会自动打开 http://127.0.0.1:<随机端口>，拖入文件即可开始转换。

右键菜单（可选）：
   python scripts/install_context_menu.py install

命令行：
   python -m crossplatform.cli --help
